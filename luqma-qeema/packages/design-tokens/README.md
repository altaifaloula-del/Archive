# @luqma-qeema/design-tokens

المصدر الوحيد لقيم الهوية: `tokens.json`. التوثيق في `brand/DESIGN_SYSTEM.md`.

```
python3 build.py   # يولّد dist/tokens.css و dist/tokens.dart
```

- لا تعدّل ملفات `dist/` يدوياً.
- أي تغيير في `tokens.json` يحتاج موافقة المالك، ويُسجَّل في `brand/BRAND_CHANGE_CONTROL.md`.
