# ACCEPTANCE_CRITERIA — معايير القبول

## أ. حالات القبول الأساسية الإلزامية (من الأمر التنفيذي §17)

لا تُقبل أي حالة إلا **بدليل مسجل**: مخرجات الاختبار الآلي، ولقطة أو سجل، وتاريخ التشغيل، والإصدار. «تم» دون دليل = غير مقبول (TST-03).
