# BRAND_CHANGE_CONTROL — سجل تغييرات الهوية

المرجع: `docs/_source/BRAND_DIRECTIVE.md` §1 و§12. أي تغيير في ملفات `brand/master-logo/` أو `brand/logo-variants/` أو `brand/colors/` أو `brand/fonts/` يحتاج:

1. موافقة خطية وصريحة من المالك، مسجلة هنا بالتاريخ والنص.
2. مراجعة في Git قبل الدمج (طلب دمج، لا رفع مباشر على الفرع الرئيسي). عند نقل المشروع إلى منظمة الشركة (OI-06) يُضاف ملف CODEOWNERS يجعل المالك مراجعاً إلزامياً لمجلد `brand/`.
3. نجاح `scripts/check_brand.py`.
