# UI/UX SPEC — v56.0

## الإطار العام (موجود — مع إضافات v56)
| العنصر | الحالة |
|---|---|
| القائمة الجانبية | كحلية بمجموعات وظيفية، تمييز الصفحة الحالية، **طي/توسيع** (`toggleSide`، محفوظ لكل جهاز)، درج على الجوال، RTL/LTR، **تُشتق من صلاحيات الدور** (`ROLES[role].tabs`) فلا تظهر وحدة بلا صلاحية |
| الشريط العلوي | رجوع/الرئيسية، رمز MITHQAL، عنوان الصفحة، **هوية المنشأة (جديد `TenantChip`)**، الإصدار، المزامنة، الحاضرون، الوضع الفاتح/الداكن، اللغة، الثيم، الطباعة، الإشعارات، الحساب |
| مساحة العمل | بطاقات `card` بكثافة متوازنة، شريط التنقل الفرعي `SecPager/OdooBar`، الجداول `tb`/`RptTable` |
| الحالات | رسائل `say(..., 'no')` صريحة بالسبب (صلاحية، إقفال، تكرار، حصة، اتصال)، مؤشرات التحميل `mod-loading`، حالات الفراغ «لا توجد بيانات» |
| التأكيد للعمليات الحساسة | `window.confirm`/`Modal` قبل الحذف والاستعادة والترحيل وإعادة الإعدادات (منها «استعادة افتراضي الهوية» الجديد) |
| التصدير والطباعة | موحّدة في `RptTable`/`rptHtml`: PDF (طباعة المتصفح) · Excel (`makeRptXlsx`) · CSV (`rptCsv`) |

## لوحات الأدوار
الرئيسية «التطبيقات أولًا» تعرض **أرقام اليوم حسب صلاحية الدور** (`homeKpis`) ومهامه (`appTaskBadges`)، ولوحات متخصصة قائمة: المدير المالي (`cfoDash`)، الموارد البشرية (`HrDashboard`)، تقرير الفرع، التحليل. **لم تُبنَ في هذا الإصدار تسع لوحات منفصلة لكل دور** (مفتوح — `DESIGN_QA_V56.md`).

## غير منفّذ (صراحةً)
- **بحث عام نصي في الشريط العلوي** — يوجد البحث الصوتي (`VoiceSearchHost`) والبحث داخل كل وحدة فقط.
- **اختصارات لوحة المفاتيح** — Escape يغلق النوافذ فقط.
- **محدد المنشأة** — كل منشأة نسخة نشر/مشروع Firebase مستقل؛ لا انتقال بين منشآت داخل الجلسة نفسها (البنية الحالية). محدد الفرع موجود في الشاشات التشغيلية.
